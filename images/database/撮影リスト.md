# スクリーンショット撮影リスト（データベース・4層アーキテクチャ編）

データベース資料（[データベース/](/データベース/)）と 4層アーキテクチャ資料（[4層アーキテクチャ/](/4層アーキテクチャ/)）に埋め込むスクリーンショットの一覧です。撮影の分担に使ってください。Git 資料の撮影リスト（[images/git/撮影リスト.md](/images/git/撮影リスト.md)）とは別のリストです。

## 撮影のルール

- **保存場所**：表の「保存パス」のとおりに保存する（フォルダは作成済み）
- **形式**：PNG。ウィンドウ全体ではなく、説明に必要な範囲を切り取る（ただし `〇〇-01-01` のような「全体」と書いてあるものは全体）
- **強調**：「強調」欄の箇所を**赤枠**（太さ 3px 程度）で囲む。番号を振る指定がある場合は ①②… を赤丸で入れる
- **個人情報**：メールアドレス、PC のユーザー名（`C:\Users\〇〇` など）が写らないようにする。**パスワード欄に実際のパスワードを表示した状態で撮らない**（講義用の仮パスワード `postgres` を使うか、伏せ字のまま撮る）
- **バージョン**：PostgreSQL 18、pgAdmin 4（インストーラ同梱版）、Windows 11 を想定。バージョンが違う場合は、資料の説明と画面が違う箇所をメモして共有する
- **表示言語**：pgAdmin は英語表示で撮影する（日本語化すると用語が資料とずれるため）
- **テーマ**：見やすさのため、ライトテーマで統一する

## 撮影の前提（サンプルデータの準備）

「撮影前に」の列に書かれた状態にしてから撮影してください。サンプルデータは、サンプルシステムのリポジトリ（URL は仮置き）の `db/` フォルダにある次の 2 つの SQL ファイルです。

1. [db/01_schema.sql](https://github.com/<ORG>/PRMN_SYSTEM_Sample/blob/main/db/01_schema.sql)（テーブル定義）
2. [db/02_seed.sql](https://github.com/<ORG>/PRMN_SYSTEM_Sample/blob/main/db/02_seed.sql)（サンプルデータ）

データベース名は `grades_db`、ユーザーは `postgres`（講義用）で統一します。
