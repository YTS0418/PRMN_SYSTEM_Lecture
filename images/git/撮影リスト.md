# スクリーンショット撮影リスト

Git 資料（[00_ドキュメント/Git/](/00_ドキュメント/Git/)）に埋め込むスクリーンショットの一覧です。撮影の分担に使ってください。

## 撮影のルール

- **保存場所**：表の「保存パス」のとおりに保存する（フォルダは作成済み）
- **形式**：PNG。ウィンドウ全体ではなく、説明に必要な範囲を切り取る（ただし `〇〇-01-01-overview` は全体）
- **強調**：「強調」欄の箇所を**赤枠**（太さ 3px 程度）で囲む。番号を振る指定がある場合は ①②… を赤丸で入れる
- **個人情報**：GitHub のユーザー名以外の個人情報（メールアドレス、トークン、他人のリポジトリ名など）が写らないようにする。**PAT（`ghp_...`）は絶対に写さない**
- **表示言語**：VSCode は日本語表示、IntelliJ IDEA は英語表示・New UI で撮影する
- **テーマ**：見やすさのため、VSCode / IntelliJ ともにライトテーマで統一するのがおすすめ

## 撮影後の差し替え方法

資料内の次のブロックを探し、
```markdown
<!-- 📷 SS: /images/git/vscode/vsc-04-03-commit.png -->
> 📷 **スクショ指定：`vsc-04-03-commit.png`**
> - 画面：…
> - 強調：…
```
次の1行に置き換えます（説明文は「画面」の内容を短くしたものでOK）。
```markdown
![コミットボタン](/images/git/vscode/vsc-04-03-commit.png)
```
