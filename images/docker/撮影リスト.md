# スクリーンショット撮影リスト（Docker 編）

Docker 資料（[Docker/](/Docker/00_はじめに.md)）に埋め込むスクリーンショットの一覧です。撮影の分担に使ってください。データベース・4層アーキテクチャ編の撮影リスト（[images/database/撮影リスト.md](/images/database/撮影リスト.md)）とは別のリストです。

## 撮影のルール

- **保存場所**：表の「保存パス」のとおりに保存する（フォルダは作成済み）
- **形式**：PNG。ウィンドウ全体ではなく、説明に必要な範囲を切り取る
- **強調**：「強調」欄の箇所を**赤枠**（太さ 3px 程度）で囲む。番号を振る指定がある場合は ①②… を赤丸で入れる
- **個人情報**：メールアドレス、PC のユーザー名（`C:\Users\〇〇` など）が写らないようにする。**パスワード欄に実際のパスワードを表示した状態で撮らない**（講義用の仮パスワードを使うか、伏せ字のまま撮る）。Docker Desktop のアカウントでサインインしている場合は、ユーザー名やメールアドレスが写らない範囲で撮る
- **バージョン**：Docker Desktop（最新の安定版）、Windows 11、PostgreSQL 18、pgAdmin 4（Docker イメージ版）を想定。バージョンが違う場合は、資料の説明と画面が違う箇所をメモして共有する
- **表示言語**：Docker Desktop と pgAdmin は、英語表示で撮影する
- **テーマ**：見やすさのため、ライトテーマで統一する

## 撮影の前提

「撮影前に」の列に書かれた状態にしてから撮影してください。Compose の設定ファイルは、サンプルシステムのリポジトリ（URL は仮置き）にあるものを使います。

1. `compose.yaml`（`db` と `pgadmin`）
2. `compose.app.yaml`（`app`）

パスワードは、撮影用の仮の値を `.env` に設定し、画面に写さないようにします。
