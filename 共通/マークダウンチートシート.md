# マークダウン チートシート

マークダウン（Markdown）は、簡単な記号を使って文書の構造を表現できる軽量マークアップ言語です。
README、ドキュメント、メモ、GitHub の Issue / PR など、開発の現場で広く使われています。

> **ポイント**: 左に「書き方」、右に「表示結果」をイメージしながら読み進めてください。
> VS Code では `Cmd + Shift + V`（Windows: `Ctrl + Shift + V`）でプレビューできます。

## 1. 見出し

`#` の数で見出しのレベルが決まります（1〜6）。`#` の後ろには**半角スペース**を入れます。

```markdown
# 見出し1
## 見出し2
### 見出し3
#### 見出し4
##### 見出し5
###### 見出し6
```

- 見出し1（`#`）は文書のタイトルとして**1つだけ**使うのが一般的です。
- 見出しのレベルは飛ばさず、順番に使いましょう（`#` の次は `##`）。

## 2. 段落と改行

- 空行で区切ると、別の段落になります。
- 同じ段落内で改行したいときは、行末に**半角スペース2つ**を入れるか、`<br>` を使います。

```markdown
これは1つ目の段落です。

これは2つ目の段落です。

行末にスペース2つ
で改行できます。
```

> 単に Enter で改行しただけでは、表示上はつながって1行になります。

## 3. 文字の装飾

| 書き方 | 表示 | 説明 |
| --- | --- | --- |
| `**太字**` | **太字** | 強調したいとき |
| `*斜体*` | *斜体* | 軽い強調 |
| `***太字かつ斜体***` | ***太字かつ斜体*** | 組み合わせ |
| `~~打ち消し線~~` | ~~打ち消し線~~ | 取り消し・不要な内容 |
| `` `インラインコード` `` | `インラインコード` | コマンドや変数名 |

```markdown
**重要**な内容は太字、*補足*は斜体、~~誤り~~は打ち消し線で表現できます。
```

> 日本語では斜体は読みにくいため、強調は**太字**を中心に使うのがおすすめです。

## 4. リスト

### 箇条書き（順序なし）

`-`、`*`、`+` のいずれかで始めます（`-` に統一するのがおすすめ）。

```markdown
- りんご
- みかん
- ぶどう
```

- りんご
- みかん
- ぶどう

### 番号付きリスト（順序あり）

```markdown
1. 材料を用意する
2. 材料を切る
3. 炒める
```

1. 材料を用意する
2. 材料を切る
3. 炒める

> 番号は `1.` `1.` `1.` のようにすべて `1.` でも、自動で連番になります。

### ネスト（入れ子）

先頭に**スペース2〜4個**（またはタブ）を入れると、階層が深くなります。

```markdown
- 果物
  - りんご
  - みかん
- 野菜
  - にんじん
  - たまねぎ
```

- 果物
  - りんご
  - みかん
- 野菜
  - にんじん
  - たまねぎ

## 5. リンクと画像

### リンク

```markdown
[表示するテキスト](https://example.com)
[ホバー時のタイトル付き](https://example.com "タイトル")
<https://example.com>
```

- [表示するテキスト](https://example.com)
- <https://example.com>（URL をそのままリンクにする書き方）

### 画像

リンクの前に `!` を付けるだけです。`[]` の中は画像が表示できないときの**代替テキスト**です。

```markdown
![代替テキスト](./images/sample.png)
![代替テキスト](https://example.com/sample.png)
```

### 相対パスの例

```markdown
[別のドキュメントへ](./02_別のファイル.md)
[上の階層へ](../README.md)
```

## 6. 引用

行頭に `>` を付けると引用になります。

```markdown
> これは引用です。
> 複数行にもできます。
>
> > 引用の中の引用（ネスト）も可能です。
```

> これは引用です。
> 複数行にもできます。
>
> > 引用の中の引用（ネスト）も可能です。

## 7. コード

### インラインコード

バッククォート `` ` `` で囲みます。

```markdown
`git commit` でコミットします。
```

`git commit` でコミットします。

### コードブロック

バッククォート3つ `` ``` `` で囲みます。開始側に**言語名**を書くとシンタックスハイライトされます。

````markdown
```python
def hello(name):
    print(f"Hello, {name}!")

hello("Markdown")
```
````

```python
def hello(name):
    print(f"Hello, {name}!")

hello("Markdown")
```

よく使う言語名: `python` / `javascript` / `typescript` / `html` / `css` / `json` / `bash` / `sql` / `diff`

### 差分の表示（diff）

```diff
- 削除された行
+ 追加された行
```

### コードブロック内にコードブロックを書く

外側のバッククォートを内側より**多く**（4つ以上）します。このチートシートの例もこの方法で書いています。

## 8. 表

`|`（パイプ）と `-`（ハイフン）で作ります。

```markdown
| 名前   | 年齢 | 職業     |
| ------ | ---- | -------- |
| 田中   | 25   | エンジニア |
| 佐藤   | 30   | デザイナー |
```

| 名前 | 年齢 | 職業 |
| --- | --- | --- |
| 田中 | 25 | エンジニア |
| 佐藤 | 30 | デザイナー |

### 列の揃え

区切り行の `:` の位置で左揃え・中央揃え・右揃えを指定します。

```markdown
| 左揃え | 中央揃え | 右揃え |
| :----- | :------: | -----: |
| a      | b        | c      |
| 100    | 200      | 300    |
```

| 左揃え | 中央揃え | 右揃え |
| :----- | :------: | -----: |
| a | b | c |
| 100 | 200 | 300 |

> 表のセル内で `|` を表示したいときは `\|` と書きます。
> 表を手書きするのが大変なときは、VS Code 拡張機能（Markdown All in One など）の整形機能が便利です。

## 9. 水平線

`---`、`***`、`___` のいずれかを単独の行に書きます。

```markdown
---
```

---

> 直前の行が文字だと見出し扱いになる場合があるため、水平線の前後には**空行**を入れましょう。

## 10. チェックリスト

`- [ ]` と `- [x]` で作ります（GitHub などで利用可能）。

```markdown
- [x] マークダウンの基本を学ぶ
- [ ] 表を書いてみる
- [ ] README を書く
```

- [x] マークダウンの基本を学ぶ
- [ ] 表を書いてみる
- [ ] README を書く

## 11. エスケープ

記号をそのまま表示したいときは、直前に `\`（バックスラッシュ）を付けます。

```markdown
\*これは斜体になりません\*
\# これは見出しになりません
1\. これは番号付きリストになりません
```

\*これは斜体になりません\*

エスケープが必要になりやすい文字: `` \ ` * _ { } [ ] ( ) # + - . ! | ``

## 12. 便利な小技

### 折りたたみ（HTML）

マークダウン内では HTML も使えます。`<details>` で折りたたみ表示ができます。

```markdown
<details>
<summary>クリックして開く</summary>

ここに隠したい内容を書きます。

</details>
```

<details>
<summary>クリックして開く</summary>

ここに隠したい内容を書きます。

</details>

### コメント（表示されないメモ）

```markdown
<!-- これは表示されないコメントです -->
```

### 脚注

```markdown
マークダウンは2004年に登場しました[^1]。

[^1]: John Gruber 氏によって考案されました。
```

### 絵文字（GitHub など）

```markdown
:smile: :rocket: :warning:
```

### Mermaid 図（GitHub など対応環境のみ）

````markdown
```mermaid
graph LR
  A[書く] --> B[プレビュー] --> C[公開]
```
````

> 脚注・絵文字・Mermaid などは**環境によって対応状況が異なります**。表示されない場合は、基本記法を使いましょう。

## 13. 練習問題

次の内容をマークダウンで書いてみましょう。

### 問題1: 自己紹介

以下を満たす自己紹介を作成してください。

- 見出し（名前）
- 好きなものを箇条書きで3つ
- 一番好きなものを**太字**にする

### 問題2: 手順書

「コーヒーの淹れ方」を、番号付きリストとコードブロック（コマンド風の記述でも可）を使って書いてください。

好きな3つの言語（Python / JavaScript / Java など）について、「用途」「難易度」を表にまとめてください。

- 音楽
