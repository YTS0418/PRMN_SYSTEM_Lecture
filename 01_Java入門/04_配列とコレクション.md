## 1. 配列

C と同じ**固定長**の配列です。作ったあとで要素数は変えられません。

```java
public class ArraySample {
    public static void main(String[] args) {
        int[] scores = new int[3];       // 要素3個、すべて 0 で初期化される
        scores[0] = 80;
        scores[1] = 65;
        scores[2] = 92;

        int[] primes = {2, 3, 5, 7, 11}; // 初期値つき宣言

        System.out.println(scores.length);   // 3  （() が付かない）
        System.out.println(primes[4]);       // 11

        for (int i = 0; i < primes.length; i++) {
            System.out.print(primes[i] + " ");
        }
        System.out.println();

        for (int p : primes) {               // 拡張for
            System.out.print(p * 2 + " ");
        }
    }
}
```

実行結果：

```
3
11
2 3 5 7 11 
4 6 10 14 22 
```

| 項目 | Java | C | Python |
|---|---|---|---|
| 宣言 | `int[] a = new int[5];` | `int a[5];` | `a = [0] * 5` |
| 要素数 | `a.length` | 自分で管理 | `len(a)` |
| 範囲外アクセス | **例外が発生**（安全） | 未定義動作 | `IndexError` |
| 型 | 同じ型のみ | 同じ型のみ | 混在OK |

### 便利な `Arrays` クラス

```java
import java.util.Arrays;

public class ArraysSample {
    public static void main(String[] args) {
        int[] a = {5, 2, 9, 1};
        System.out.println(a);                  // [I@1b6d3586 のような値 (ダメ)
        System.out.println(Arrays.toString(a)); // [5, 2, 9, 1]

        Arrays.sort(a);                         // 昇順ソート
        System.out.println(Arrays.toString(a)); // [1, 2, 5, 9]

        int[] b = new int[4];
        Arrays.fill(b, 7);
        System.out.println(Arrays.toString(b)); // [7, 7, 7, 7]
    }
}
```

> 配列をそのまま `println` すると、中身ではなくアドレスのような文字列が出ます。`Arrays.toString` を使いましょう。

## 2. 多次元配列

```java
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(grid[1][2]);        // 6
System.out.println(grid.length);       // 2 （行数）
System.out.println(grid[0].length);    // 3 （列数）

for (int[] row : grid) {
    for (int v : row) {
        System.out.print(v + " ");
    }
    System.out.println();
}
```

## 3. コレクションとは

配列は長さが固定なので不便です。そこで Java には、**要素数を後から増減できるデータ構造**が標準で用意されています。まとめて**コレクション**と呼び、`java.util` パッケージにあります。

| 種類 | 特徴 | Python で近いもの |
|---|---|---|
| `ArrayList` | 順序あり、重複OK、番号でアクセス | `list` |
| `HashMap` | キーと値のペア | `dict` |
| `HashSet` | 重複なし、順序の保証なし | `set` |

### ジェネリクス `< >`

コレクションは「**何の型を入れるか**」を `< >` で指定します。

```java
ArrayList<String> names = new ArrayList<>();   // String のリスト
ArrayList<Integer> nums = new ArrayList<>();   // Integer のリスト
```

- `<>` の中には**クラス型**を書く。`int` ではなく **`Integer`**、`double` ではなく **`Double`**（基本型に対応するクラスを**ラッパークラス**と呼ぶ）
- 型を指定することで、違う型を入れようとするとコンパイルエラーになる（安全）

| 基本型 | ラッパークラス |
|---|---|
| `int` | `Integer` |
| `double` | `Double` |
| `boolean` | `Boolean` |
| `char` | `Character` |
| `long` | `Long` |

`int` と `Integer` の変換は自動で行われるので、ふだんは意識しなくて構いません。

## 4. ArrayList

```java
import java.util.ArrayList;

public class ArrayListSample {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        list.add("apple");           // 末尾に追加
        list.add("banana");
        list.add("cherry");
        list.add(1, "orange");       // 位置1に挿入

        System.out.println(list);                // [apple, orange, banana, cherry]
        System.out.println(list.size());         // 4
        System.out.println(list.get(2));         // banana   （list[2] ではない）

        list.set(0, "grape");                    // 置き換え
        list.remove("banana");                   // 値で削除
        list.remove(0);                          // 位置で削除

        System.out.println(list);                // [orange, cherry]
        System.out.println(list.contains("cherry")); // true
        System.out.println(list.isEmpty());      // false

        for (String s : list) {
            System.out.println(s);
        }
    }
}
```

実行結果：

```
[apple, orange, banana, cherry]
4
banana
[orange, cherry]
true
false
orange
cherry
```

### よく使うメソッド

| 操作 | メソッド | Python |
|---|---|---|
| 追加 | `add(x)` | `append(x)` |
| 取得 | `get(i)` | `a[i]` |
| 更新 | `set(i, x)` | `a[i] = x` |
| 削除 | `remove(i)` / `remove(x)` | `pop(i)` / `remove(x)` |
| 個数 | `size()` | `len(a)` |
| 検索 | `contains(x)` / `indexOf(x)` | `x in a` / `index(x)` |
| 全削除 | `clear()` | `clear()` |
| ソート | `Collections.sort(list)` | `sort()` |

> `ArrayList<Integer>` で `remove(1)` と書くと、**値 1 の削除ではなく位置 1 の削除**になります。値で消したい場合は `remove(Integer.valueOf(1))` と書きます。

### 配列との変換

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;

ArrayList<Integer> nums = new ArrayList<>(Arrays.asList(5, 2, 9, 1));
Collections.sort(nums);
System.out.println(nums);       // [1, 2, 5, 9]
Collections.reverse(nums);
System.out.println(nums);       // [9, 5, 2, 1]
System.out.println(Collections.max(nums)); // 9
```

## 5. HashMap

キーと値の組を保存します（Python の `dict`）。

```java
import java.util.HashMap;
import java.util.Map;

public class HashMapSample {
    public static void main(String[] args) {
        HashMap<String, Integer> scores = new HashMap<>();

        scores.put("Taro", 80);          // 追加（同じキーなら上書き）
        scores.put("Hanako", 95);
        scores.put("Jiro", 70);

        System.out.println(scores.get("Hanako"));            // 95
        System.out.println(scores.get("Nobody"));            // null （無い場合）
        System.out.println(scores.getOrDefault("Nobody", 0)); // 0
        System.out.println(scores.containsKey("Taro"));      // true
        System.out.println(scores.size());                   // 3

        scores.remove("Jiro");

        for (Map.Entry<String, Integer> e : scores.entrySet()) {
            System.out.println(e.getKey() + " -> " + e.getValue());
        }
    }
}
```

実行結果（順序は保証されません）：

```
95
null
0
true
3
Taro -> 80
Hanako -> 95
```

| 操作 | Java | Python |
|---|---|---|
| 追加・更新 | `m.put(k, v)` | `m[k] = v` |
| 取得 | `m.get(k)` | `m[k]` |
| 存在確認 | `m.containsKey(k)` | `k in m` |
| 削除 | `m.remove(k)` | `del m[k]` |
| キー一覧 | `m.keySet()` | `m.keys()` |
| 値一覧 | `m.values()` | `m.values()` |

> `HashMap` は**順序を保証しません**。追加順で取り出したいなら `LinkedHashMap`、キー順なら `TreeMap` を使います。

### 単語の出現数を数える例

```java
import java.util.HashMap;

public class WordCount {
    public static void main(String[] args) {
        String[] words = {"a", "b", "a", "c", "b", "a"};
        HashMap<String, Integer> count = new HashMap<>();

        for (String w : words) {
            count.put(w, count.getOrDefault(w, 0) + 1);
        }
        System.out.println(count);   // {a=3, b=2, c=1}
    }
}
```

## 6. HashSet

**重複を許さない**集合です（Python の `set`）。

```java
import java.util.HashSet;

public class HashSetSample {
    public static void main(String[] args) {
        HashSet<Integer> set = new HashSet<>();
        set.add(3);
        set.add(5);
        set.add(3);        // 重複なので無視される

        System.out.println(set);            // [3, 5]
        System.out.println(set.size());     // 2
        System.out.println(set.contains(5)); // true
        set.remove(3);
        System.out.println(set);            // [5]
    }
}
```

## 7. 使い分け・Python との対応表

| やりたいこと | 使うもの |
|---|---|
| 要素数が決まっていて固定 | 配列 `int[]` |
| 順番に並べて増減したい | `ArrayList` |
| 名前などで値を引きたい | `HashMap` |
| 重複を除きたい / 含むか高速に調べたい | `HashSet` |

```
Python:  nums = [1, 2, 3]           → Java: ArrayList<Integer> nums = new ArrayList<>(List.of(1, 2, 3));
Python:  d = {"a": 1}               → Java: HashMap<String, Integer> d = new HashMap<>(); d.put("a", 1);
Python:  s = {1, 2, 3}              → Java: HashSet<Integer> s = new HashSet<>(List.of(1, 2, 3));
```

## 8. よくあるミス

| ミス | 対処 |
|---|---|
| `ArrayIndexOutOfBoundsException` | 添字が `0 〜 length-1` を超えている。ループの条件が `<=` になっていないか確認 |
| `IndexOutOfBoundsException`（ArrayList） | `size()` を超えた位置を `get` した |
| `int` を `<>` に書いた（`ArrayList<int>`） | `ArrayList<Integer>` と書く |
| `list[0]` / `list.length` と書く | `list.get(0)` / `list.size()`。配列と使い方が違う |
| `NullPointerException` | `map.get(k)` が `null` を返したのに、そのまま使った。`getOrDefault` を使う |
| ループ中に `list.remove` | `ConcurrentModificationException`。`removeIf` などを使う |

## 9. 練習問題

**問1.** 配列 `{64, 25, 12, 22, 11}` の最大値と最小値を、`Arrays.sort` を使わずに求めてください。

**問2.** `ArrayList<String>` に好きな果物を 5 つ追加し、文字数が 5 より長いものだけを表示してください。

**問3.** 文字列 `"mississippi"` に含まれる各文字の出現回数を `HashMap<Character, Integer>` で数えて表示してください（ヒント：`charAt` と拡張 for 文）。

**問4.** `int[]` `{1, 2, 2, 3, 3, 3, 4}` から重複を除いた要素数を `HashSet` で求めてください。

**問1**
```java
int[] a = {64, 25, 12, 22, 11};
int max = a[0], min = a[0];
for (int v : a) {
    if (v > max) max = v;
    if (v < min) min = v;
}
System.out.println("max=" + max + ", min=" + min);   // max=64, min=11
```

```java
import java.util.ArrayList;
```

```java
import java.util.HashMap;

public class CharCount {

        }

    }
}
```

```java
import java.util.HashSet;
```
