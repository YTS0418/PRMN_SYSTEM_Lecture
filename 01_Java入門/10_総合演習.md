## 2. 設計

クラスを役割ごとに分けます。**1 つのクラスは 1 つの責任だけ**を持たせるのが、きれいな設計のコツです。

| クラス | 役割 | 使う知識 |
|---|---|---|
| `Student` | 学生 1 人分のデータ | クラス、カプセル化、例外（06, 08 章） |
| `StudentManager` | 学生のリストを管理（追加・検索・集計・保存） | ArrayList、ファイル入出力（04, 09 章） |
| `Main` | メニュー表示と入力の受け付け | Scanner、ループ、switch（02, 03 章） |

```
Main ──使う──→ StudentManager ──持つ──→ ArrayList<Student>
```

ファイル構成：

```
grades/
├── Student.java
├── StudentManager.java
└── Main.java
```

## 3. ステップ1：Student クラス

**仕様**
- フィールド：`name`（String）、`score`（int）。どちらも `private`
- 点数は 0〜100 の範囲のみ許可。範囲外なら `IllegalArgumentException` を投げる
- `getName()`, `getScore()`, `toString()` を持つ

```java
public class Student {
    private final String name;
    private final int score;

    public Student(String name, int score) {
        if (name == null || name.isBlank()) {
            throw new IllegalArgumentException("名前が空です");
        }
        if (score < 0 || score > 100) {
            throw new IllegalArgumentException("点数は0〜100にしてください: " + score);
        }
        this.name = name;
        this.score = score;
    }

    public String getName() { return name; }
    public int getScore() { return score; }

    @Override
    public String toString() {
        return String.format("%-10s %3d点", name, score);
    }
}
```

> `final` を付けているので、作成後に値を変更できないクラスになります。値が勝手に変わらないので安全です。

## 4. ステップ2：StudentManager クラス

**仕様**
- `add(Student)`：追加
- `list()`：一覧表示
- `average()`：平均点（学生がいない場合は 0）
- `top()`：最高得点の `Student`（いない場合は `null`）

```java
import java.util.ArrayList;
import java.util.List;

public class StudentManager {
    private final List<Student> students = new ArrayList<>();

    public void add(Student s) {
        students.add(s);
    }

    public void printAll() {
        if (students.isEmpty()) {
            System.out.println("学生が登録されていません");
            return;
        }
        for (int i = 0; i < students.size(); i++) {
            System.out.println((i + 1) + ". " + students.get(i));
        }
    }

    public double average() {
        if (students.isEmpty()) return 0;
        int sum = 0;
        for (Student s : students) {
            sum += s.getScore();
        }
        return (double) sum / students.size();
    }

    public Student top() {
        Student best = null;
        for (Student s : students) {
            if (best == null || s.getScore() > best.getScore()) {
                best = s;
            }
        }
        return best;
    }

    public int size() {
        return students.size();
    }
}
```

> `List<Student> students = new ArrayList<>();` — 変数の型は**インタフェース `List`**、実体は `ArrayList`（[07 章](07_継承とポリモーフィズム.md) の考え方）。

ここまでで簡単に動作確認できます。

```java
public class Test {
    public static void main(String[] args) {
        StudentManager m = new StudentManager();
        m.add(new Student("Taro", 80));
        m.add(new Student("Hanako", 95));
        m.printAll();
        System.out.println("平均: " + m.average());
        System.out.println("最高: " + m.top());
    }
}
```

実行結果：

```
1. Taro        80点
2. Hanako      95点
平均: 87.5
最高: Hanako      95点
```

## 5. ステップ3：ファイルへの保存と読み込み

**仕様**
- `save(String path)`：1 行 1 人、`名前,点数` の形式で保存
- `load(String path)`：ファイルを読み込んで追加。ファイルがなければ何もしない
- ファイル関連の `IOException` は**呼び出し元に投げる**（`throws`）

`StudentManager` に次のメソッドを追加します（先頭に `import java.io.IOException; import java.nio.file.*;` を追加）。

```java
    public void save(String path) throws IOException {
        List<String> lines = new ArrayList<>();
        for (Student s : students) {
            lines.add(s.getName() + "," + s.getScore());
        }
        Files.write(Path.of(path), lines);
    }

    public void load(String path) throws IOException {
        Path p = Path.of(path);
        if (!Files.exists(p)) return;

        for (String line : Files.readAllLines(p)) {
            if (line.isBlank()) continue;
            String[] parts = line.split(",");
            try {
                students.add(new Student(parts[0], Integer.parseInt(parts[1].trim())));
            } catch (IllegalArgumentException | ArrayIndexOutOfBoundsException e) {
                System.out.println("不正な行をスキップ: " + line);
            }
        }
    }
```

ポイント：

- 不正な行があっても、全体を止めずにスキップする（[08 章](08_例外処理.md)）
- `NumberFormatException` は `IllegalArgumentException` の子なので、まとめて捕まえられる

## 6. ステップ4：メニュー（Main）

```java
import java.io.IOException;
import java.util.Scanner;

public class Main {
    private static final String FILE = "students.csv";

    public static void main(String[] args) {
        StudentManager manager = new StudentManager();
        Scanner sc = new Scanner(System.in);

        try {
            manager.load(FILE);
        } catch (IOException e) {
            System.out.println("読み込みに失敗しました: " + e.getMessage());
        }

        boolean running = true;
        while (running) {
            printMenu();
            System.out.print("選択 > ");
            String choice = sc.nextLine().trim();

            switch (choice) {
                case "1" -> addStudent(manager, sc);
                case "2" -> manager.printAll();
                case "3" -> System.out.printf("平均点: %.1f%n", manager.average());
                case "4" -> {
                    Student top = manager.top();
                    System.out.println(top == null ? "データがありません" : "最高得点者: " + top);
                }
                case "5" -> {
                    try {
                        manager.save(FILE);
                        System.out.println("保存しました");
                    } catch (IOException e) {
                        System.out.println("保存に失敗しました: " + e.getMessage());
                    }
                }
                case "0" -> running = false;
                default -> System.out.println("0〜5 を入力してください");
            }
            System.out.println();
        }
        sc.close();
        System.out.println("終了します");
    }

    private static void printMenu() {
        System.out.println("===== 成績管理 =====");
        System.out.println("1. 学生を追加");
        System.out.println("2. 一覧表示");
        System.out.println("3. 平均点を表示");
        System.out.println("4. 最高得点者を表示");
        System.out.println("5. ファイルに保存");
        System.out.println("0. 終了");
    }

    private static void addStudent(StudentManager manager, Scanner sc) {
        try {
            System.out.print("名前 > ");
            String name = sc.nextLine();
            System.out.print("点数 > ");
            int score = Integer.parseInt(sc.nextLine().trim());

            manager.add(new Student(name, score));
            System.out.println("追加しました");
        } catch (NumberFormatException e) {
            System.out.println("点数は整数で入力してください");
        } catch (IllegalArgumentException e) {
            System.out.println("入力エラー: " + e.getMessage());
        }
    }
}
```

コンパイルして実行：

```bash
javac Student.java StudentManager.java Main.java
java Main
```

`nextInt()` ではなく `nextLine()` + `Integer.parseInt()` を使っているのは、[02 章](02_基本文法・変数と型.md) で触れた**改行の読み残し**を避けるためです。

## 7. 発展課題

少しずつ機能を増やして、自分の力で拡張してみましょう。

1. **名前で検索**：`Student find(String name)` を作る（見つからなければ `null` または独自例外）
2. **削除機能**：名前を指定して学生を削除する
3. **点数順に並べて表示**：`students.sort((a, b) -> b.getScore() - a.getScore());`（ラムダ式。`Comparator` の使い方を調べてみましょう）
4. **成績ランク（S/A/B/C/F）**：`Student` に `getGrade()` を追加。`switch` 式を使う
5. **科目の追加**：`HashMap<String, Integer>` で複数科目の点数を持つ
6. **`record` を使った書き換え**：`Student` を [06 章](06_クラスとオブジェクト.md) の `record` で書き換えて比較する

## 8. よくあるエラー集

| エラー・症状 | 原因 | 対処 |
|---|---|---|
| `cannot find symbol` | スペルミス、`import` 忘れ、変数の宣言忘れ | 行番号と記号名を確認 |
| `incompatible types` | 型の不一致（`int` に `String` など） | 型を確認し、必要ならキャスト・変換 |
| `';' expected` | `;` の付け忘れ | エラー行の**前の行**も確認 |
| `class X is public, should be declared in a file named X.java` | クラス名とファイル名が違う | 名前を合わせる |
| `missing return statement` | `return` が通らない経路がある | すべての分岐で `return` する |
| `variable might not have been initialized` | 初期化前に使った | 値を代入してから使う |
| `non-static ... cannot be referenced from a static context` | `static` から非 `static` を呼んだ | オブジェクトを作る、または `static` にする |
| `unreported exception` | チェック例外の処理漏れ | `try-catch` か `throws` |
| `NullPointerException` | `null` のオブジェクトを使った | どの変数が `null` かメッセージで確認 |
| `ArrayIndexOutOfBoundsException` | 添字の範囲外 | `length` / `size()` を確認、ループ条件を見直す |
| `ClassNotFoundException` / `Could not find or load main class` | クラス名の指定ミス、フォルダが違う | `java Main`（`.class` を付けない）、`main` を持つクラスか確認 |
| 日本語が化ける | 文字コードの不一致 | UTF-8 を指定、IDE のエンコーディング設定を確認 |

### エラーが出たときの手順
1. **エラーメッセージを最後まで読む**（英語でも、種類と行番号は分かる）
2. **一番上の行・自分のコードが書かれた行**を見る
3. その行の**前後**を確認する（原因が前の行にあることも多い）
4. 分からなければ、**メッセージをそのまま検索**する（英語のまま検索するのがコツ）
5. `System.out.println` で途中経過の値を表示して確認する
