## 1. この資料について

- 対象：Java 未経験者（C言語・Python は大学の授業レベルで学習済み）
- 使用バージョン：**Java 17 以降（LTS）**。この資料のコードは Java 21 で動作確認しています
- ゴール：クラスを使った小規模なプログラム（ファイル入出力・例外処理を含む）を自力で書けるようになること

## 3. 前提知識

次のことが分かっていれば十分です。

- 変数、if 文、for / while、関数の基本（C か Python のどちらかで OK）
- コマンドライン（ターミナル）で `cd` や `ls`（`dir`）が使える

オブジェクト指向の知識は不要です。06 章から一から説明します。

## 4. サンプルコードの実行方法

### 方法 A：ターミナルから実行する（01 章で環境構築後）

```bash
javac Hello.java     # コンパイル（Hello.class ができる）
java Hello           # 実行（拡張子 .class は付けない）
```

### 方法 B：1 ファイルなら直接実行できる（Java 11 以降）

```bash
java Hello.java      # コンパイルと実行を一度に行う
```

小さなサンプルを試すときに便利です。

### 方法 C：IDE（IntelliJ IDEA / VSCode）で実行する

「▶ 実行」ボタンで実行できます。詳細は [01 章](01_Javaとは・環境構築.md) を参照してください。

## 5. 各章の書き方

各章は次の順で進みます。

1. **この章のゴール**：何ができるようになるか
2. **説明とコード例**：実行結果つき。自分で打ち込んで動かすのがおすすめです
3. **C / Python との対比表**：すでに知っている言語と対応づけて覚える
4. **よくあるミス**
5. **練習問題**：解答例は折りたたんであります。先に自分で考えてみてください

> 💡 コードは**コピペせず、手で打ち込む**ほうが身につきます。エラーメッセージを読む練習にもなります。
