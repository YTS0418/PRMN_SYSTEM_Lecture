## 1. 演算子

C とほぼ同じです。

| 種類 | 演算子 | 例 |
|---|---|---|
| 算術 | `+ - * / %` | `a % b` |
| 代入 | `= += -= *= /= %=` | `x += 5` |
| インクリメント | `++ --` | `i++` |
| 比較 | `== != < > <= >=` | `a >= b` |
| 論理 | `&&` `\|\|` `!` | `a > 0 && b > 0` |
| 三項 | `条件 ? 真の値 : 偽の値` | `n % 2 == 0 ? "偶数" : "奇数"` |

### Python との違い

| Python | Java |
|---|---|
| `and` / `or` / `not` | `&&` / `\|\|` / `!` |
| `x ** 2` | `Math.pow(x, 2)` |
| `a // b` | `a / b`（int 同士のとき） |
| `1 < x < 10` | `1 < x && x < 10`（連鎖比較は不可） |
| `x if c else y` | `c ? x : y` |

```java
public class Operators {
    public static void main(String[] args) {
        int a = 10, b = 3;
        System.out.println(a / b);                 // 3
        System.out.println(a % b);                 // 1
        System.out.println(Math.pow(a, 2));        // 100.0
        System.out.println(a > 5 && b > 5);        // false
        System.out.println(a > 5 || b > 5);        // true

        int i = 5;
        System.out.println(i++);   // 5 を表示してから 6 になる
        System.out.println(i);     // 6
        System.out.println(++i);   // 7 にしてから表示

        String result = (a % 2 == 0) ? "偶数" : "奇数";
        System.out.println(result); // 偶数
    }
}
```

実行結果：

```
3
1
100.0
false
true
5
6
7
偶数
```

## 2. if 文

条件は必ず `( )` で囲み、**`boolean` 型の式**でなければなりません（C のように `if (x)` で整数を使うことはできません）。

```java
public class IfSample {
    public static void main(String[] args) {
        int score = 72;

        if (score >= 80) {
            System.out.println("優");
        } else if (score >= 70) {
            System.out.println("良");
        } else if (score >= 60) {
            System.out.println("可");
        } else {
            System.out.println("不可");
        }
    }
}
```

実行結果：

```
良
```

| | else if の書き方 |
|---|---|
| Python | `elif` |
| C / Java | `else if` |

> 処理が 1 文でも **`{ }` は省略しない**ことを強くおすすめします。省略するとバグの元になります。

### 文字列の条件は equals

```java
String cmd = "start";
if (cmd.equals("start")) {
    System.out.println("開始します");
}
```

## 3. switch 文・switch 式

### 従来の switch 文（C と同じ）

`break` を書かないと次の case に**落ちていく（フォールスルー）**ので注意します。

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("月");
        break;
    case 2:
        System.out.println("火");
        break;
    case 3:
        System.out.println("水");
        break;
    default:
        System.out.println("その他");
}
// 水
```

### 新しい switch 式（Java 14 以降）

`->` を使うと `break` が不要で、値も返せます。**新しく書くならこちらがおすすめ**です。

```java
public class SwitchSample {
    public static void main(String[] args) {
        String day = "SAT";

        String type = switch (day) {
            case "MON", "TUE", "WED", "THU", "FRI" -> "平日";
            case "SAT", "SUN" -> "休日";
            default -> "不明";
        };

        System.out.println(type);   // 休日
    }
}
```

Python の `match` 文に近い使い方ができます。`switch` は `int`、`char`、`String`、`enum` などで使えます（`double` や `boolean` は不可）。

## 4. for 文

### 基本の for（C と同じ）

```java
for (int i = 0; i < 5; i++) {
    System.out.print(i + " ");
}
// 0 1 2 3 4
```

`for (初期化; 継続条件; 更新)` の形で、Python の `for i in range(5)` に相当します。

| Python | Java |
|---|---|
| `for i in range(5):` | `for (int i = 0; i < 5; i++)` |
| `for i in range(1, 10, 2):` | `for (int i = 1; i < 10; i += 2)` |
| `for i in range(10, 0, -1):` | `for (int i = 10; i > 0; i--)` |

### 拡張 for 文（for-each）

配列やリストの要素を順に取り出します。Python の `for x in list:` とほぼ同じです。

```java
public class ForEach {
    public static void main(String[] args) {
        int[] scores = {80, 65, 92};
        int sum = 0;
        for (int s : scores) {      // 「scores の各要素を s として」と読む
            sum += s;
        }
        System.out.println("合計: " + sum);   // 合計: 237
    }
}
```

### 九九の例（二重ループ）

```java
public class Table {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 9; j++) {
                System.out.printf("%3d", i * j);
            }
            System.out.println();
        }
    }
}
```

実行結果：

```
  1  2  3  4  5  6  7  8  9
  2  4  6  8 10 12 14 16 18
  3  6  9 12 15 18 21 24 27
```

## 5. while / do-while

```java
int n = 1;
while (n <= 100) {      // 条件を先にチェック
    n *= 2;
}
System.out.println(n);  // 128

int k = 10;
do {                    // 最低 1 回は実行される
    System.out.println("k = " + k);
    k++;
} while (k < 10);
// k = 10 と 1 回だけ表示
```

## 6. break と continue

```java
public class BreakContinue {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) continue;   // 偶数はスキップ
            if (i > 7) break;           // 7 を超えたら終了
            System.out.print(i + " ");
        }
    }
}
```

実行結果：

```
1 3 5 7 
```

## 7. よくあるミス

| ミス | 説明 |
|---|---|
| `if (x = 5)` | 代入になっているのでコンパイルエラー（Java では `int` は条件に使えない） |
| 文字列に `==` | `equals` を使う |
| `for` 末尾の `;` | `for (...);` と書くと本体が空になる |
| `case` の `break` 忘れ | 従来の switch で次の case まで実行される。`->` 形式なら発生しない |
| 無限ループ | `while (true)` の中に `break` がない / 更新式を書き忘れた |

## 8. 練習問題

**問1.** 1 から 100 までの整数の合計を `for` で求めてください。

**問2.** 1 から 30 までを表示し、3 の倍数のときは数字の代わりに `Fizz`、5 の倍数なら `Buzz`、両方なら `FizzBuzz` を表示してください。

**問3.** 整数 `n` を入力して、素数かどうかを判定してください。

**問4.** `*` を使って次の三角形を表示してください（高さ 4）。

```
*
**
***
****
```

**問1**
```java
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;

System.out.println(sum);   // 5050
```

**問2**
```java
public class FizzBuzz {
    public static void main(String[] args) {
        for (int i = 1; i <= 30; i++) {

                System.out.println("FizzBuzz");
            } else if (i % 3 == 0) {
                System.out.println("Fizz");
            } else if (i % 5 == 0) {
                System.out.println("Buzz");

                System.out.println(i);
            }
        }
    }
}
```

**問3**
```java
import java.util.Scanner;

public class Prime {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        boolean isPrime = n >= 2;
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                isPrime = false;
                break;
            }
        }
        System.out.println(n + (isPrime ? "は素数です" : "は素数ではありません"));
        sc.close();
    }
}
```

**問4**
```java
for (int i = 1; i <= 4; i++) {
    for (int j = 0; j < i; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```
