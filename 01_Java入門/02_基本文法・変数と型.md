## 1. 変数の宣言

Java は**静的型付け**です。変数には必ず型を指定します（C と同じ。Python のように型なしで代入はできません）。

```java
public class Variables {
    public static void main(String[] args) {
        int age = 20;              // 整数
        double height = 170.5;     // 小数
        String name = "Taro";      // 文字列
        boolean isStudent = true;  // 真偽値

        System.out.println(name + " " + age + " " + height + " " + isStudent);

        age = 21;                  // 再代入はOK
        // age = "twenty";         // エラー：int に文字列は入れられない
        System.out.println(age);
    }
}
```

実行結果：

```
Taro 20 170.5 true
21
```

| | 宣言と代入 |
|---|---|
| Python | `age = 20`（型は書かない、後で別の型を入れてもOK） |
| C | `int age = 20;` |
| Java | `int age = 20;`（C と同じ。一度決めた型は変えられない） |

### 変数名のルール
- 英数字・`_`・`$` が使える。先頭は数字にできない
- 予約語（`class`, `int`, `if` など）は使えない
- 慣習：**変数・メソッドは `camelCase`**（`studentName`）、**クラスは `PascalCase`**（`StudentList`）

## 2. 基本データ型

Java には **8 種類の基本データ型（プリミティブ型）** があります。よく使うのは太字の 4 つです。

| 型 | サイズ | 範囲・用途 | 例 |
|---|---|---|---|
| `byte` | 1 byte | -128〜127 | `byte b = 10;` |
| `short` | 2 byte | 約 ±3 万 | `short s = 1000;` |
| **`int`** | 4 byte | 約 ±21 億 | `int n = 100;` |
| `long` | 8 byte | 約 ±922 京 | `long big = 10000000000L;` |
| `float` | 4 byte | 小数（精度低） | `float f = 1.5f;` |
| **`double`** | 8 byte | 小数（標準） | `double d = 1.5;` |
| **`boolean`** | - | `true` / `false` | `boolean ok = true;` |
| `char` | 2 byte | **1 文字** | `char c = 'A';` |

ポイント：

- **`long` のリテラルは末尾に `L`**、`float` は末尾に `f` が必要（`10000000000L`）
- **`char` は `' '`（シングルクォート）、String は `" "`（ダブルクォート）**。別物です
- C と違い、`int` は**必ず 4 byte**（環境で変わらない）
- `boolean` は `true` / `false` のみ。C のように `0` / `1` で代用できない

```java
public class Types {
    public static void main(String[] args) {
        int max = Integer.MAX_VALUE;
        System.out.println(max);        // 2147483647
        System.out.println(max + 1);    // オーバーフロー！
        long big = 10000000000L;
        System.out.println(big);

        char c = 'A';
        System.out.println(c);          // A
        System.out.println(c + 1);      // 66 （char は数値としても扱われる）
        System.out.println((char)(c + 1)); // B
    }
}
```

実行結果：

```
2147483647
-2147483648
10000000000
A
66
B
```

> ⚠️ Python の `int` は桁数無制限ですが、Java の `int` は**オーバーフローする**ので注意。大きな値は `long` を使います。

## 3. 文字列 String

`String` は基本データ型ではなく**クラス**（だから大文字始まり）ですが、よく使うので基本のように扱えます。

```java
public class Strings {
    public static void main(String[] args) {
        String s = "Hello, Java";

        System.out.println(s.length());          // 11
        System.out.println(s.charAt(0));         // H   （s[0] ではない！）
        System.out.println(s.substring(7));      // Java
        System.out.println(s.substring(0, 5));   // Hello
        System.out.println(s.toUpperCase());     // HELLO, JAVA
        System.out.println(s.indexOf("Java"));   // 7
        System.out.println(s.contains("Hello")); // true
        System.out.println(s.replace("Java", "World")); // Hello, World

        String a = "Hello";
        String b = "Hel" + "lo";                 // 連結は +
        System.out.println(a + " " + b + " " + 100); // Hello Hello 100
    }
}
```

実行結果：

```
11
H
Java
Hello
HELLO, JAVA
7
true
Hello, World
Hello Hello 100
```

### ⚠️ 文字列の比較は `==` ではなく `equals`

```java
public class StringEquals {
    public static void main(String[] args) {
        String a = "abc";
        String b = new String("abc");

        System.out.println(a == b);       // false （同じ「オブジェクト」か？を比べている）
        System.out.println(a.equals(b));  // true  （「中身」が同じか？を比べている）
    }
}
```

`String` を含む**クラスの型は、`==` だと「同じ実体か」を比較**します。中身の比較には必ず `equals` を使います。Python の `==` とは違うので特に注意してください。

> `String` は**変更不可（イミュータブル）**。`toUpperCase()` などは元の文字列を変えず、新しい文字列を返します。

## 4. 型変換

### 自動変換（小さい型 → 大きい型）

```java
int i = 10;
double d = i;      // OK: 10.0
long l = i;        // OK
```

### 明示的変換：キャスト（大きい型 → 小さい型）

```java
double d = 3.99;
int i = (int) d;   // 3  （小数部は切り捨て。四捨五入ではない）
```

### 整数同士の割り算に注意

```java
public class Division {
    public static void main(String[] args) {
        System.out.println(7 / 2);        // 3    （int同士 → int）
        System.out.println(7 / 2.0);      // 3.5
        System.out.println((double) 7 / 2); // 3.5
        System.out.println(7 % 2);        // 1
    }
}
```

実行結果：

```
3
3.5
3.5
1
```

> Python では `7 / 2` が `3.5` になりますが、Java は **C と同じく整数同士なら整数除算**です（Python の `//` 相当）。

### 文字列 ⇄ 数値

```java
int n = Integer.parseInt("123");        // "123" → 123
double d = Double.parseDouble("3.14");  // "3.14" → 3.14
String s1 = String.valueOf(456);        // 456 → "456"
String s2 = "" + 456;                   // 同じ結果（簡易的な方法）
```

数値でない文字列を渡すと `NumberFormatException` が発生します（[08 章](08_例外処理.md) で対処法を扱います）。

## 5. 定数 final

`final` を付けた変数は**再代入できません**。定数には `final` + 大文字のスネークケースを使うのが慣習です。

```java
final double TAX_RATE = 0.10;
// TAX_RATE = 0.08;   // エラー: cannot assign a value to final variable
```

## 6. var による型推論

Java 10 以降は、右辺から型が決まる場合に `var` が使えます。

```java
var count = 10;          // int と推論される
var message = "hello";   // String
```

**型が消えるわけではなく**、コンパイラが自動で決めているだけです（後から別の型は入れられません）。この資料では、型が分かりやすいように基本的に型を明示します。

## 7. 出力の書式 printf

C と同じ `printf` が使えます。

```java
public class Printf {
    public static void main(String[] args) {
        String name = "Taro";
        int age = 20;
        double score = 85.678;

        System.out.printf("名前: %s, 年齢: %d歳%n", name, age);
        System.out.printf("点数: %.1f点%n", score);
        System.out.printf("[%5d] [%-5d] [%05d]%n", 42, 42, 42);
    }
}
```

実行結果：

```
名前: Taro, 年齢: 20歳
点数: 85.7点
[   42] [42   ] [00042]
```

| 書式 | 意味 |
|---|---|
| `%d` | 整数 |
| `%f` / `%.2f` | 小数 / 小数点以下 2 桁 |
| `%s` | 文字列 |
| `%c` | 1 文字 |
| `%n` | 改行（Java では `\n` より `%n` が推奨） |
| `%5d` / `%-5d` / `%05d` | 幅 5 右寄せ / 左寄せ / 0 埋め |

Python の f 文字列 `f"{name}"` に相当するものは、`String.format("...", ...)` か、Java 15 以降の `formatted` です。

```java
String msg = String.format("%sさんは%d歳", "Taro", 20);
```

## 8. キーボード入力 Scanner

`Scanner` クラスを使います（C の `scanf`、Python の `input()` に相当）。

```java
import java.util.Scanner;           // Scanner を使うために必要

public class Input {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("名前を入力: ");
        String name = sc.nextLine();       // 1行読む

        System.out.print("年齢を入力: ");
        int age = sc.nextInt();            // 整数を読む

        System.out.println(name + "さんは来年" + (age + 1) + "歳です");
        sc.close();
    }
}
```

実行例（`>` が入力）：

```
名前を入力: > Taro
年齢を入力: > 20
Taroさんは来年21歳です
```

| メソッド | 読み込むもの |
|---|---|
| `nextLine()` | 1 行（改行まで） |
| `next()` | 空白区切りの 1 単語 |
| `nextInt()` | 整数 |
| `nextDouble()` | 小数 |

> `import java.util.Scanner;` は「別の場所にある Scanner クラスを使う」という宣言です（C の `#include`、Python の `import` に相当）。`System` や `String` は自動で読み込まれるので不要です。

> ⚠️ `nextInt()` の後に `nextLine()` を呼ぶと、**改行が残っていて空文字が返る**ことがあります。その場合は間に `sc.nextLine();` を 1 回入れて捨てます。

## 9. よくあるミス

| ミス | 例 | 対処 |
|---|---|---|
| 型の不一致 | `int x = 3.5;` → `incompatible types: possible lossy conversion` | `(int)` でキャスト、または `double` を使う |
| 文字列を `==` で比較 | `if (s == "abc")` | `s.equals("abc")` |
| 初期化忘れ | `int x; System.out.println(x);` → `variable x might not have been initialized` | 使う前に必ず代入する |
| `char` と `String` の混同 | `char c = "A";` | `char c = 'A';` |
| 整数除算 | `int avg = (a + b) / 2;` で小数が出ない | `double` を使う / `/ 2.0` |

## 10. 練習問題

**問1.** 半径 5 の円の面積を `double` で計算して表示してください（円周率は `Math.PI`、小数第 2 位まで）。

**問2.** 3 科目の点数 `80`, `75`, `92` から平均点を、**小数点以下まで**求めて表示してください。

**問3.** キーボードから整数を 2 つ入力させ、和・差・積・商（整数除算）・余りを表示してください。

**問4.** 文字列 `"java programming"` を大文字に変換し、文字数も合わせて表示してください。

**問1**
```java
public class Circle {
    public static void main(String[] args) {
        double r = 5;
        double area = Math.PI * r * r;

    }
}
```

**問2**
```java
public class Average {
    public static void main(String[] args) {
        int a = 80, b = 75, c = 92;
        double avg = (a + b + c) / 3.0;   // 3.0 にするのがポイント
        System.out.printf("平均: %.2f%n", avg);   // 平均: 82.33
    }
}
```

**問3**
```java
import java.util.Scanner;

public class Calc {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();
        System.out.println("和: " + (a + b));
        System.out.println("差: " + (a - b));
        System.out.println("積: " + (a * b));
        System.out.println("商: " + (a / b));
        System.out.println("余り: " + (a % b));
        sc.close();
    }
}
```
`b` が 0 のときは実行時エラー（`ArithmeticException`）になります。08 章で対処法を学びます。

```java
public class Upper {

    }
}
```
